# User tests

Three people with no science background. Give each one the site for 30 seconds
without help, then ask the two questions. Write the answers down word for word.

Target answers:
1. The air is warming low down and cooling high up.
2. Fairly sure for most heights, not sure for some. (Any mention of the labels counts.)
